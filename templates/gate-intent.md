# Intent gate checklist

**Question:** is this worth doing, who owns it, how risky is it?
**Accountable decider:** data product owner (GATE-04).

- [ ] Named consumer and the decision the data supports
- [ ] Accountable owner named (ACT-02)
- [ ] Risk tier assigned: criticality, reversibility, blast radius (PHS-02)
- [ ] Reuse search done; the reason to build something new is recorded (CTX-07, CTX-10)
- [ ] Effort and running-cost estimate attached
- [ ] Change class identified, with its current autonomy level

**Outcomes:** go / go with a smaller scope / reuse an existing asset / no.

Decision record (GATE-03): decider, outcome, evidence version, date.
